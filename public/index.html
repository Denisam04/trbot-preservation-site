01 / PRESERVATION & CONTINUITY

Denisam TAP

Denisam Trading Agency Preservation.
A defined home for project memory.

Keep documents, code and decisions connected to their history.

The existing personal desktop application packages approved project materials into encrypted, separate versions and supports integrity and recovery checks. Coverage and automation are verified per source and workflow; complete historical capture is not claimed.

01 — SCOPE

Intentional collection

Approved directories and reviewed materials define the boundary. Finding a file does not authorize its backup.

02 — PRESERVE

Versions with context

Local encryption, version identifiers and integrity hashes help retain the relationship between work and evidence.

03 — VERIFY

Recovery, checked

Download and restore checks establish what can be recovered. A local or synchronized copy alone is not proof.

GOOGLE DRIVE CONNECTION

Access limited to the task.

The optional Drive API connection requests only drive.file: files created by or explicitly opened with the app, within the owner's selected workflow. It does not request account-wide Drive access.

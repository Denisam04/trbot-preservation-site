Local-first · Owner-controlled

Keep the work.
Preserve the context.

Encrypted project backups, version history and recovery checks. TrBot Preservation helps its owner retain the documents, code and decisions that make a project recoverable.

Understand your data

From approved files to checked recovery.

01 / SELECT

A defined project scope

Local rules select approved project files. Unknown sources require review; discovery alone does not authorize a backup.

02 / PRESERVE

Encrypted, separate versions

The desktop tool packages reviewed files, encrypts the archive locally and preserves version identifiers and integrity hashes.

03 / VERIFY

Recovery is a separate check

A local or synchronized copy is not proof of a verified cloud backup. Download and restore checks establish what can actually be recovered.

Google Drive integration

Access selected for the task.

The optional Google Drive API connection requests only drive.file: access to files created by or explicitly opened with the app. It supports storing and checking encrypted archives in the owner's selected folder. It does not request account-wide Drive access.

Google Drive for desktop is a separate optional transport with its own permissions. Its installation does not broaden this application's OAuth scope.

A personal preservation tool.

TrBot Preservation is operated for its owner's project. This public website provides application and privacy information; it does not accept archive uploads, provide a public backup service, or expose project files. It is not a trading platform or financial dashboard.

Recovery depends on retained archives and the owner's separate recovery materials. No service can guarantee permanent access or recovery under every failure condition.
